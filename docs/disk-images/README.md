# Diagnostic disk images

Reference images used by the dynamic-trace and copy-protection investigation. They are
**test/reference data only** — copyright remains with the original publishers/preservation
projects. Files are included so the traces in `../drive-assembly/README.md` and
`../../tools/diagnostics/README.md` are reproducible without the external archive.

## Arctic Fox (Electronic Arts, 1986)

| File | Description |
|---|---|
| `arcticfox[ea_1986](!).g64` | Preservation G64 from the C64 Preservation Project (raw GCR, 84 half-track slots, no half-tracks present). Attached to emulated drive 8 with `-drive8truedrive` by `tools/diagnostics/launch-x64sc-g64.sh`. |
| `arcticfox[ea_1986](!).nbz` | Original MNIB-1541-RAW NBZ (LZ77-compressed) from the same project. |
| `af-g64.d64` | D64 decoded from the G64 above with `--convert`; 106 sectors undecodable (protected areas). |
| `arcticfox.d64` | D64 decoded from the NBZ above with `--convert`. |
| `kjr.d64` | Kracker Jax "Revealed Trilogy" side 1 decoded from NBZ; contains `KJ DOCS`, `TGREAD`, loaders. |

## Kracker Jax

| File | Description |
|---|---|
| `kracker_jax_revealed_trilogy_s1/s2*.nbz` | Original NBZ images from the preservation archive (side 2 contains `TGREAD`). |
| `kracker_jax_revealed_trilogy_s1/s2*.d64` | Decoded D64 versions produced by `--convert`. |
| `kracker_jax_vol1..vol7*.d64` | Decoded D64s from the remaining Kracker Jax volumes, generated by `tools/diagnostics/scan_kj.sh` during the "fat track" text search. |

## Regenerating

```bash
# NBZ -> D64 (all of them)
for f in *.nbz; do
  dotnet run --project D64Editor.App --no-build -- --convert "$f" "${f%.nbz}.d64"
done

# G64 -> D64
dotnet run --project D64Editor.App --no-build -- \
  --convert 'arcticfox[ea_1986](!).g64' af-g64.d64
```

Generated images (e.g. `generated/protected-repro.g64`) are documented in
[`generated/README.md`](generated/README.md).

See `tools/diagnostics/README.md` for the VICE launchers and binary-monitor clients that use
these images.
