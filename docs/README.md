# Reference documents

These are local reference extractions, not source code.

- `inside-commodore-dos.txt` — plain-text extraction of
  *Inside Commodore DOS* by Richard Immers & Gerald G. Neufeld (1984), made with
  `pdftotext -layout` from the locally owned PDF
  `0835930912 Inside Commodore DOS [Immers & Neufeld 1984-01-01] {D9F347BA}.pdf` in the
  Commodore book collection. Copyright remains with the authors/publisher; this text is kept
  only as a local development reference (1541 VIA registers, stepper phases, speed zones,
  GCR routines, job queue).

A search of the local `_COMMODORE` PDF collection found no other Commodore DOS reference;
the only other disk-related item was a 1541 hardware schematic.
